# 계획 파일

`generate.py`·`chain.py`에 `--plan`으로 넘기는 파일이다. **계획을 파일로 받으면 같은
조항에 같은 지시가 재현된다** — 시간 초과로 잃은 호출을 다시 부를 수 있었던 것도 이
덕이다. 그래서 끝난 실행의 계획도 지우지 않는다.

각 폴더의 `run.sh`는 **저장소 뿌리로 `cd`한 뒤** 최상위 기준 경로로 계획을 가리킨다.
폴더를 옮기면 `cd`의 깊이와 `--plan` 경로를 함께 고쳐야 한다.

## 끝난 것 — `archive/`

**지운 것이 아니라 내린 것이다.** 최상위에 살아 있는 것만 남기려고 옮겼다. 각 폴더의
경위는 `../CHANGELOG.md`에 있다.

| --- | --- | --- |
| `archive/probe/` | 1차 본 생성 전 탐침. 지시 배분·정규식 고장 넷을 여기서 찾았다 | 2026-08-13 |
| `archive/probe2/` | 재탐침. 같은 조항에 `늘었다`·`줄었다`를 둘 다 걸어 짝 비교 | 2026-08-13 |

| `archive/smoke/` | 2차 1패스 본 생성 직전 확인. 5개 문서 × 10건 | 2026-08-19 |

**`archive/smoke/`의 실행 출력은 산출에 안 섞는다.** `runs/_smoke/` 아래에 따로 두었다 —
