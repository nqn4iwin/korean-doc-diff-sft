당신은 공공문서의 개정 전후를 대조해 무엇이 어떻게 바뀌었는지 설명하는 분석자입니다.

[이전판] $before_id
$before

[최신판] $after_id
$after

━━ 1단계. 실질 변경인지 먼저 판단합니다 ━━

판단 기준은 **글자가 달라졌는지가 아니라, 이 문서가 규정하는 권리·의무·조건·절차·
적용 범위 중 하나라도 달라졌는지**입니다. 하나도 달라지지 않았다면 judgement는
negative, labels는 빈 배열로 두고 거기서 멈춥니다.

아래는 그 기준을 적용한 예입니다. **목록에 없는 경우에도 위 기준으로 판단하세요.**

- 다른 조항이 신설·삭제되어 조·항·호 번호가 밀린 것 (제27조 → 제28조)
- 다른 조항을 가리키는 인용 번호가 그 밀림을 따라 바뀐 것
- 항목기호, 띄어쓰기, 문장부호, 같은 뜻의 표기 차이
- 문서 자체의 제·개정일자나 판번호 표기 ((2020. 12. 4. 개정) → (2024. 9. 27. 개정))

이것들은 숫자나 날짜가 바뀌지만 **수치·기준이나 기한·시점이 아닙니다.** 조항이 요구하는
내용이 하나도 달라지지 않았기 때문입니다.

━━ 2단계. 무엇이 바뀌었나 (대상 7종) ━━

- 기한·시점 : 날짜, 기간, 처리 기한, 시행일이 바뀐다
    (문서 자체의 제·개정일자 표기는 제외 — 1단계로 갑니다)
- 수치·기준 : 금액, 비율, 개수, 등급이 바뀐다. 인용하는 조문이 다른 조문으로 교체된다
    (번호만 밀린 인용은 제외 — 1단계로 갑니다)
- 적용 범위 : 규정이 미치는 대상·경우의 폭이 바뀐다
- 수행 주체 : 일을 하거나 책임지는 쪽이 바뀐다
- 절차·요건 : 밟아야 할 단계나 갖춰야 할 조건이 바뀐다
- 제출물·기재사항 : 내야 하거나 적어야 하는 항목이 바뀐다
- 명칭 : 무언가를 가리키는 이름이나 연락 지점이 바뀐다. 가리켜지는 것 자체는 그대로다

━━ 3단계. 어떻게 바뀌었나 (방향 5종) ━━

- 늘었다 : 대상의 폭·크기·개수가 커졌다
- 줄었다 : 대상의 폭·크기·개수가 작아졌다
- 다른 값 : 커지지도 작아지지도 않고 다른 값이 됐다
- 새로 생겼다 : 개정 전 조항에 그 대상이 아예 없었다
- 없어졌다 : 개정 후 조항에 그 대상이 남지 않았다

`늘었다·줄었다`와 `새로 생겼다·없어졌다`는 **개정 전 조항에 그 대상이 있었는지**로
가릅니다. 있었으면 앞의 둘, 없었으면 뒤의 둘입니다.

방향의 주어는 **대상**이지 바뀐 조각이 아닙니다. `전문기관` → `전문기관 및 운영기관`
에서 새로 생긴 것은 운영기관이지만, 이 조항에는 개정 전에도 수행 주체가 있었으므로
`(수행 주체, 늘었다)`입니다.

━━ 작성 규칙 ━━

1. 대상과 방향은 위 목록의 말만 씁니다. 새로 지어내지 마세요.
2. 같은 (대상, 방향) 쌍을 두 번 쓰지 마세요.
3. 바뀐 것이 여러 가지면 labels에 여러 개를 넣으세요. 같은 대상에 방향이 반대인 변경이
   함께 있을 수도 있습니다.
4. direct_impact에는 조항이 무슨 말인지 다시 쓰지 마세요. 이 개정으로 **누가** 무엇을
   하게 되거나 하지 못하게 되는지를 쓰세요. 조항을 수행하는 쪽과 영향을 받는 쪽이 다를
   수 있고, 여럿이면 모두 씁니다.
5. 개정 이유나 기관의 의도는 단정하지 마세요.

━━ 출력 형식 ━━

아래 JSON 하나만 출력하세요. 설명 문장을 덧붙이지 마세요.
{
  "judgement": "positive 또는 negative",
  "labels": [
    { "대상": "...", "방향": "...", "근거": "바뀐 구간만 '이전 → 이후' 형태로" }
  ],
  "direct_impact": "누가 무엇을 하게 되거나 하지 못하게 되는지"
}
