# 세션 브리프

**세션을 시작할 때 이것만 읽는다.** 자기 역할 절과 아래 「공통」만 보면 되고, 다른
역할 절은 안 읽어도 된다. 더 필요할 때만 각 절이 가리키는 문서로 내려간다.

이 문서는 **오늘 어디서 이어 하는지**를 적는다. 설계는 `학습데이터_생성_프로세스.md`,
경위는 각 역할의 `CHANGELOG.md`, 할 일 목록은 `TODO.md`에 있다.

누가 영향을 받는지**를 해석하는 SFT 데이터. 학습은 별도 저장소 `model_train`이 맡는다.

수정된 것으로 잡고 작성자 이름도 안 남는다. 검색도 `git.exe grep`을 쓴다.

## 역할 A 세션 — 해석

블록쌍을 받아 `judgement` / `labels` / `impacts` / `direct_impact` 넷을 낸다.
설계는 `docs/학습데이터_생성_프로세스.md` 3-2절.

**지금 상태**

| | |
| --- | --- |
| 프롬프트 | v2.2 (2026-08-10에 잠금). 온도 0.2 |
| 채점 | AM1~AM4·AM6 100% / AM5 54.2% / AM7 91.7% / AM8 95.8% / AH1 93.3% (튜닝 24호출) |
| 나간 것 | 실질 변경 697건에 해석을 붙여 학습 레코드 605건을 뽑았고 1차 학습이 끝났다 |
| 도구 | `annotate.py`(배치 해석) · `export.py`(학습 레코드) · `run.py`(평가 세트 채점) |

**A-1은 끝났고 A-2가 남았다.** A-1은 "역할 B에게 줄 few-shot 예시 만들기"였고 검증됐다.
A-2는 "역할 B가 지어낸 합성 pair 6,000건에 해석을 자동으로 붙이기"이며, **착수 전에
끝내기로 한 선행조건 넷 중 3번이 마지막으로 남았다.**

| | 선행조건 | 상태 |
| --- | --- | --- |
| 1 | 홀드아웃 열기 | 유출 교체는 끝났다. 여는 것은 아직 |
| 2 | 착수 기준 확정 | 모양은 정해졌고 값이 비어 있다 (표본 100건에 1인이 3단 라벨을 붙여 그 자리에서 선을 긋는다. 기준 항목은 AM4와 AH1) |
| 3 | **유사도 선별기 문턱값 0.60 재설정** | 근거 자료가 생겼다 — 697건의 `restatement_ratio` 분위수 |
| 4 | `direct_impact`의 사실 정확성 채점 항목 신설 | **끝났다.** AM9가 `rubric.md` 40행에 있다 — `labels[].근거`의 `이전 → 이후`를 뒤집어 적지 않았는지 원문에 대고 잰다. 남은 것은 커버리지 68~78%를 넓힐지인데 **뒤집힘이 0건이라 급하지 않다** |

**같이 볼 것** — AM8 채점기가 주체를 문장에 통째로 들어 있는지로만 봐서 오탐을 낸다.
697건에서 실패 109건 중 56건이 오탐이었고, 대안 구현이 `export.py`의 `subject_survives()`에
이미 있다. A-2를 돌리기 전에 정해야 수치가 처음부터 맞는다.

**negative를 목표치 10%로 줄이는 것은 하지 않는 쪽으로 답이 나왔다.** `model_train`이
2026-08-18에 실측했다 — negative를 뺀 조건은 **두 라운드 다 "무조건 positive"로 붕괴**했고
값이 소수점까지 같았다. 반대로 1차 스윕의 negative 45.9%에서는 70개 중 43개가 "무조건
negative"로 붕괴했다. **너무 많아도 너무 적어도 무너진다.** 1,655건의 16.0%에서는 잘
돌았으므로 그 근처가 목표다. **기획서 2.2.3의 10%는 이 실측 전에 잡은 값이다.**

**남은 판단은 하나** — 605건의 계열 쏠림(처리방침 60%)을 학습·평가 분할에 어떻게
반영할지. 코드가 아니라 판단이다.

### 2026-08-13에 고친 것 넷 — 전부 `generate.py`

**탐침을 먼저 돌려서 찾았다.** 100건(1차)과 60건(재탐침)에 25분을 썼고, 그냥 본 생성을
갔으면 **277건이 지시와 어긋난 채로** 나왔을 것이다. 폐기가 아니라 라벨이 갈아끼워지면서
채우려던 칸이 조용히 비었을 것이라 **5시간을 다 쓰고 나서야 알았다.**

| | 무엇 | 효과 |
| --- | --- | --- |
| 1 | 지시 배분 — 성립하는 지시를 전부 후보에 담고, 조항당 상한은 뽑을 때 걸고, **공급이 적은 지시부터** 고른다 | `수행 주체` 59.6% → 21.9% |
| 2 | `NUMBER`에 `개(?!월)` — 경계가 없어 `3개월`이 `3개`로 걸렸다 | `수치·기준` 지시가 기한 조항에 걸리던 8건이 0건 |
| 3 | `(수치·기준, 다른 값)` → **`늘었다` + `줄었다`** | BM5 **5% → 95%** |
| 4 | `(기한·시점, 다른 값)` → **`늘었다` + `줄었다`** | BM5 **17% → 90%** |

3·4번은 `(절차·요건, 늘었다)` → `새로 생겼다`와 같은 자리다. **수가 바뀌면 늘거나 줄지
"다른 값"이 되지 않는다.** 역할 A가 대상은 잘 회수하는데(89%) 방향 이름이 달라 BM5만
깎이고 있었다. **정의로 정한 것이 아니라 A가 실제로 어떻게 읽는지로 정했다.**

재탐침은 같은 조항에 `늘었다`·`줄었다`를 둘 다 걸어 **방향 지시만 다른 짝 비교**로 했다.
30쌍 중 `지시대로 갈렸다` 20쌍, `조항이 방향을 정한다` 3쌍. **합격 기준을 결과 보기 전에
확정**해 두고 통과시켰다(`조항이 방향을 정한다` 10쌍 미만 + 건별 BM5 58% 이상. 58%는
이미 받아들인 지시 중 제일 낮은 값이라 임의값이 아니다).

`수행 주체`를 안 거는 것이 답이고 C4는 벌이 아니라 예방이 된다. 아직 안 넣었다.
