# PLAN

## Goal

실제 공공·업무 문서 pair의 변경을 근거와 함께 해석하는 SFT 데이터를 만든다.
합성은 실제 pair의 변경 유형·문서 구조를 확인한 뒤에만 시작한다.

## Current phase

실제 pair를 확정하고 원문 diff를 구조화하는 단계다.

## Next steps

1. 인사혁신처 10쌍과 한국마케팅진흥원 1쌍의 원문 위치·전후 span·변경 유형을
   manifest로 정리한다.
2. 공정위 신유형 상품권 표준약관 2020 HWP ↔ 2024 HWPX의 본문 diff를 완성한다.
3. 조건부·후보 원천을 같은 채택 기준으로 검증해 문서 유형 다양성을 확보한다.
4. 실제 pair에서 관찰한 패턴을 검토하고, 합성 규칙과 negative 기준을 확정한다.
5. 그 뒤에만 소규모 합성 파일럿을 만들고 검수한다.

## Done when

- 각 채택 pair에 양쪽 공식 원문, 연결 근거, 추출 본문, SHA-256, 변경 block이 있다.
- 실제 변경과 `실질 변경 없음` 사례가 분리돼 있다.
- 학습용 pair와 보존 평가 pair가 문서 단위로 분리돼 있다.
- 합성 시작 전, 실제 변경 분포와 허용할 합성 규칙이 검토돼 있다.
