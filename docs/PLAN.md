# 최종 후보 데이터 수집 계획

저장소는 아래 두 후보만 준비한다. 세부 수집 계획과 파일럿 진행 내용은 각 후보 폴더에서 관리한다.

- `01_public_data_review/`: 법령·공공데이터포털 기반 활용 사전검토 데이터 수집 및 검증
- `02_rfp_analysis/`: 사전규격·입찰공고·첨부문서 기반 RFP 변경점 분석 데이터 수집 및 검증

공통 원칙은 다음과 같다.

- 원천·중간·처리 데이터는 `data/<프로젝트명>/`에 다시 수집한다.
- API 키와 수집 원본은 Git에 추가하지 않는다.
- 출처, 요청 조건, 수집 시각과 체크섬은 프로젝트 manifest에 기록한다.
- Solar 파일럿은 각 프로젝트의 `prompt_test/`에서 재실행·검토한다.
