# Source Selection

이 문서는 이 프로젝트에서 어떤 원문을 실제 데이터로 쓸지, 무엇을 아직 후보로만
둘지 정한 기준 문서다. 대상은 한국어 공개 공공·업무 문서의 **실제 이전판과
최신판**이다. 합성 데이터는 실제 pair에서 변경 유형·문서 구조를 충분히 관찰한 뒤에만
만든다.

## Pair acceptance rule

한 pair는 아래 조건을 모두 만족할 때만 실제 데이터로 채택한다.

1. 이전판과 최신판의 공식 원문을 각각 열 수 있다.
2. 시행일, 문서번호, 등록번호, 공식 이전판 링크 등으로 같은 기반 문서임을 보인다.
3. HTML·PDF·HWP·HWPX 등에서 비교 가능한 텍스트를 추출할 수 있다.
4. 추출 본문에서 실제 변경 블록을 확인한다.
5. 원문 URL, 수집 시각, MIME, 파일 크기, SHA-256, 추출 결과를 manifest에 남긴다.

제목 유사도, 보도자료, 변경 안내문만으로는 pair를 만들지 않는다. 법령·자치법규는
범위에서 제외한다. 행정규칙은 일반 규범 자체를 모으는 경우에는 제외하되, 연구개발사업
등의 집행 절차를 정하는 기관 운영지침·사업시행지침이면 이 분류에 포함한다.

## 수집에서 반복 확인된 함정

1. **파일명으로 버전을 판정하지 않는다.** 중기부 팁스 원공고의 첨부 파일명은
   `(최종)_..._공고(수정).hwpx`였지만 본문 머리글은 원공고인 제2026-40호였다.
   독립 사본(울산지방중소벤처기업청 미러)으로 교차검증해 원본임을 확인했다.
2. **게시글의 첨부는 조용히 교체된다.** 정정이 발생하면 원공고 게시글의 첨부가
   수정본으로 바뀌는 경우가 있다. 정정 이전 원본은 다른 기관의 미러에서 찾는다.
3. **HWP 배포용 문서는 본문이 암호화돼 있다.** 팁스 운영지침은 2024년 이후 버전이
   모두 배포용 문서다. 보호 해제는 다운로드 제한 우회이므로 시도하지 않고 후보에서
   제외한다.
4. **PDF 추출본을 pair의 한쪽으로 쓰지 않는다.** 같은 문서라도 PDF 추출은 띄어쓰기가
   뭉개져 HWPX 대비 문자 포함률이 0.776에 그쳤다. 양쪽을 같은 형식으로 맞춘다.
5. **공문으로 배포되는 문서는 공개 게시물이 아니다.** 평가편람처럼 대상기관에만
   배포되는 문서는 각 기관의 결재문서 원문공개에서만 나오고, 기관이 첨부를 비공개로
   올리면 확보할 수 없다.

## Collection workflow

1. `source_data/`에서 원문과 메타데이터를 수집한다.
2. 양쪽 파일의 형식·MIME·SHA-256·텍스트 추출 결과를 기록한다.
3. 조항·문단·표 행 단위의 deterministic diff를 만들고, 실제 변경만 남긴다.
4. 변경 유형을 기간, 수치, 대상, 범위, 의무 수준, 예외, 책임 주체, 절차, 제출물 등으로 기록한다.
5. 실제 pair의 변경 분포와 문서 구조를 검토한다.
6. 그 뒤에만 `probes/`에서 통제된 합성 예시를 만든다.

합성에서는 원문 전체를 새로 쓰지 않는다. 실제 문서의 조항·표 구조와 문체를
유지하고, 실제 pair에서 관찰한 패턴만 변경한다. 이동·번호 변경·동의어 교체처럼
의미가 바뀌지 않은 사례는 `실질 변경 없음` negative로 유지한다.
