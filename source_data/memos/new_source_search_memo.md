# 5개 분류 밖 원천 탐색 메모

## 작성 목적과 범위

기존 5개 분류를 늘리지 않고, `docs/원천데이터_선정_프로세스.md`의 pair 수락 규칙(이전·최신
공식 원문, 같은 기반 문서의 연결 근거, 추출 가능한 본문, 실제 변경)을 통과할 수 있는
새 원천 계열을 찾았다. 조사일은 2026-08-06이다. 파일은 내려받지 않았다. 따라서
파일 크기는 게시 페이지/검색 색인에 나온 경우만 적었고, HEAD 요청이 403으로 막힌
나라장터 첨부는 `미확인`으로 남겼다. 이는 수집 단계에서 원문을 받을 때 확정한다.

`보호 없음`은 로그인·열람 암호가 없이 웹 검색 색인에서 본문이 노출된다는 뜻일 뿐,
파일을 열어 확인한 값은 아니다.

**판정: 채택 (실제 pair 성립 확인).** 다만 이 사례만으로는 본문 변경 블록을 아직
검증하지 않았으므로, 실제 수집 때 두 원문의 MIME·바이트 수·SHA-256과 변경 span을
확정해야 한다. 정정 사유가 과업내용서 수정까지 명시되어 있어 단순 게시일 변경보다
의미 있는 변경일 가능성이 높다.

**권고: 지금 수집.** 같은 번호의 `000/001`을 우선 1쌍만 받아 본문 변경이 실제로
공고문에도 남는지 확인한 뒤 계열 확장 여부를 정한다.

## 조사 결론

5개 분류 밖에도 **쓸 만한 원천은 하나 확인됐다**. 나라장터의 `입찰공고·정정공고`는
같은 공고번호의 `000/001` 차수와 정정문 내 이전 번호 인용으로 연결이 명시되어 있고,
공개 원문도 각각 남는다. 따라서 기존 `제안요청서`와 구분되는 새 원천 계열로 바로
소규모 수집 검증을 할 가치가 있다. 반면 공시, 채용, 환경평가, 법령·입법예고는 이번
확인 범위에서 원문 쌍의 보존·연결 또는 선정 규칙을 통과하지 못했으므로, 지금 늘릴
원천으로는 권하지 않는다.
