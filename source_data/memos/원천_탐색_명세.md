# 원천 문서 pair 탐색 명세

웹 탐색 담당자(사람 또는 에이전트)에게 그대로 넘기는 문서다. 저장소 사정을 몰라도
읽을 수 있게 썼다.

---

## 무엇을 찾는 일인가

**같은 문서의 서로 다른 두 시점 판본**을 찾는다. 한 쌍이 "원본 → 개정본"이 되고, 둘을
비교해 무엇이 바뀌었는지 분석하는 데 쓴다.

닮은 두 문서가 아니라 **같은 문서의 앞뒤 판본**이어야 한다. 예를 들어 A기관 지침과
B기관 지침은 아무리 비슷해도 쓸 수 없다. A기관 지침의 2022년판과 2023년판이라야 한다.

---

## 필수 조건 네 개

네 개를 **모두** 만족해야 채택된다. 하나라도 어긋나면 보내지 말 것.

### 1. 같은 문서 계열임이 문서 자체로 증명될 것

"같아 보인다"는 근거가 되지 않는다. 아래 중 **하나 이상**이 있어야 한다.

- 두 문서가 **같은 고유번호**를 달고 있다 (예: 표준약관 제10069호가 개정 후에도 유지)
- 새 문서가 **옛 문서를 명시적으로 가리킨다** (예: "공고 제2026-40호를 수정한 공고입니다")
- 사이트가 **이전 판본 링크를 스스로 보존**한다 (예: "이전 방침 보기")
- 문서 안에 **개정 이력**이 있어 앞 판본을 특정할 수 있다

무엇으로 증명했는지 보고에 반드시 적는다.

### 2. 두 판본 모두 공개 접근이 될 것

로그인, 회원가입, 결제, 기관 내부망이 필요하면 탈락. 공식 발행처가 올린 것이라야 하고
블로그나 뉴스 재게시본은 안 된다.

### 3. 파일 형식

우선순위가 있다. **PDF만 있는 pair는 채택 불가다.**

| 형식 | 판정 |
| --- | --- |
| HWPX (`.hwpx`) | 가장 좋음 |
| HTML (웹페이지 본문) | 좋음 |
| HWP (`.hwp`, 한글 구버전) | 조건부. 두 판본 다 HWP면 보내되 그렇다고 표시 |
| PDF만 | **탈락.** 문단 단위로 잘라낼 수 없다 |

한쪽이 PDF고 다른 쪽이 HWPX면 그것도 탈락이다. 양쪽을 같은 방식으로 잘라내야 비교가
된다.

### 4. 실질적인 내용 변경이 있을 것

날짜·번호만 바뀐 판본은 쓸모가 없다. 반대로 문서가 통째로 다시 쓰였어도 쓸 수 없다.

- **너무 비슷하면 탈락** — 개정일자와 조 번호만 다른 경우
- **너무 다르면 탈락** — 목차 구조가 완전히 달라 대응이 안 되는 경우

거칠게라도 확인하는 법: 두 문서의 목차를 나란히 놓아 **항목의 절반 이상이 같은 제목**
으로 남아 있으면 통과. 실제로 이 조건에서 떨어진 사례가 아래 "이미 실패한 것"에 있다.

---

## 무엇을 우선할 것인가

| 우선순위 | 문서 종류 | 현재 확보 | 목표 | 한 쌍에서 나오는 변경 |
| ---: | --- | ---: | ---: | ---: |
| **1** | 기관 운영지침 · 사업시행지침 | 1쌍 | **6쌍** | **46건** |
| **2** | 제안요청서 / 사전규격–입찰공고 | 0쌍 | 3쌍 | 아직 모름 |
| **3** | 표준약관 | 3쌍 | 6쌍 | 2~4건 |
| — | 지원사업 공고 · 정정공고 | 3쌍 | **채워짐** | 3건 |
| — | 개인정보처리방침 | 15쌍 | **더 필요 없음** | 28건 |

### 왜 이 순서인가

맨 오른쪽 칸이 이유다. **문서 한 쌍에서 뽑히는 변경 건수가 종류마다 열 배 넘게
차이난다.** 실제로 세어 본 값이다.

- **기관 운영지침 한 쌍에서 46건이 나온다.** 분량이 크고 개정할 때 여러 조항을 한꺼번에
  손대기 때문이다. 게다가 부처·전문기관마다 다른 지침을 쓰므로 종류의 다양성도 같이
  얻는다. 그래서 1번이다.
- **정정공고는 한 쌍에서 3건뿐이다.** 원래 두세 군데만 고치는 문서다. 이 종류로 수량을
  채우려면 서른 쌍 넘게 필요하므로, **유형 대표성 확보용으로만 쓰고 수량은 기대하지
  않는다.** 세 쌍으로 이미 충분하다.
- **표준약관도 한 쌍에 2~4건으로 적다.** 다만 업종이 수십 가지라 **다양성 때문에**
  받는다. 수량을 기대하고 받는 것이 아니다.

즉 1·2번은 수량과 다양성을 같이 노리고, 3번은 다양성만 노린다.

### 한 계열에서 몇 쌍까지 받나

**최대 3쌍이다.** 한 기관이 판본 10개를 보존하고 있어도 3쌍만 받는다. 같은 문서가 열 번
변한 것은 열 개의 사례가 아니라 하나의 사례에 가깝다.

개인정보처리방침은 이미 한 기관에서 15쌍을 확보했고 더 늘려도 얻는 것이 없다. **다른
기관의 처리방침도 받지 않는다.**

## 이미 시도해서 실패한 것 — 반복하지 말 것

| 대상 | 왜 떨어졌나 |
| --- | --- |
| 행정안전부 공공데이터 평가편람 2024 ↔ 2025 | 2025년판 공식 원문을 못 찾았고, 찾은 후보는 2024년판과 목차가 거의 겹치지 않았다 (조건 4) |
| 팁스 총괄 운영지침 2024년 이후 판본 | 배포용 HWP로만 나와 있다 (조건 3) |
| 한국마케팅진흥원 사전규격 ↔ 입찰공고 | 양쪽 다 PDF뿐이다 (조건 3) |

---

## 뒤져볼 만한 곳

아래는 가설이다. 확인되지 않았으니 없으면 없다고 보고하면 된다.

**제안요청서 (우선순위 1)**
나라장터(g2b.go.kr)에는 **사전규격 공개** 뒤 **입찰공고**가 이어지는 제도가 있고,
입찰공고가 사전규격 등록번호를 달고 있어 조건 1이 자동으로 충족된다. 문제는 첨부가
대부분 PDF라는 것이다. **HWPX 또는 HWP 첨부가 붙은 건으로 좁혀서** 찾아야 한다.
사전규격에 대한 의견 접수 후 규격이 바뀐 건이면 조건 4도 만족한다.

**지원사업 공고 (우선순위 2)**
정정공고·수정공고 제도가 있는 부처 공고는 전부 후보다. 정정공고가 원공고 번호를
본문에 적기 때문에 조건 1이 쉽다. 중소벤처기업부 외에 과학기술정보통신부,
산업통상자원부, 고용노동부, 문화체육관광부 등의 사업 공고 게시판을 보면 된다.
**서로 다른 부처에서 한 쌍씩** 가져오는 것이 같은 부처에서 세 쌍 가져오는 것보다 낫다.

**기관 운영지침 (우선순위 1 — 여기에 제일 힘을 쓸 것)**
국가연구개발사업을 집행하는 전문기관들이 각자 사업운영요령·관리지침을 내고 개정한다.
한국산업기술기획평가원, 한국콘텐츠진흥원, 정보통신기획평가원, 한국연구재단, 중소기업
기술정보진흥원 등의 자료실을 본다. 개정 시 이전 판본을 남겨두는 곳을 찾는 것이 관건이다.

연구개발 분야 밖에도 같은 성격의 문서가 많다. 지자체 보조금 관리지침, 사회복지시설
운영지침, 공공기관 내부 규정 중 공개된 것, 각 부처의 사업시행지침이 모두 후보다.
**분량이 크고 개정 이력이 남아 있는 지침일수록 좋다.**

한 가지 유의점이 있다. 지침류는 개정 시 **전문 개정**(문서를 통째로 다시 씀)과 **일부
개정**(일부 조항만 손댐)이 있는데, 전문 개정은 조건 4의 "너무 다르면 탈락"에 걸릴
가능성이 높다. 제목에 `일부개정`이 붙은 것을 먼저 본다.

**표준약관 (우선순위 4)**
공정거래위원회 표준약관은 **고유번호가 개정 후에도 유지**되므로 조건 1이 가장 확실하다.
이미 확보한 것은 온라인게임(제10069호), 모바일게임(제10078호), 신유형 상품권 셋이다.
**다른 업종의 표준약관**을 찾으면 장르 다양성까지 얻는다 — 예식업, 학원, 이사화물,
헬스장, 대부거래, 아파트 표준관리규약 등 수십 종이 있다. 공정위 표준약관 목록에서
개정 이력이 둘 이상인 번호를 고르면 된다.

## 무엇을 보내면 되는가

pair 하나마다 아래를 적어 보낸다. **파일을 받아둘 필요는 없다. 주소와 근거면 된다.**

```
1. 문서 이름            :
2. 발행 기관            :
3. 이전 판본 URL        :
4. 최신 판본 URL        :
5. 파일 형식            : HWPX / HTML / HWP / (PDF면 보내지 말 것)
6. 같은 계열이라는 근거   : 조건 1의 넷 중 무엇으로 확인했는지, 그 문구를 그대로 인용
7. 내용 변경이 있다는 근거 : 눈에 띄게 달라진 조항 두세 개를 짧게
8. 문서 종류            : 위 우선순위 표의 다섯 중 하나
```

**확실하지 않으면 확실하지 않다고 적어 보낸다.** 조건에 맞지 않는 것을 맞는 것처럼
보내는 쪽이, 후보를 적게 보내는 것보다 훨씬 손해가 크다. 검증에 드는 품이 더 든다.

한 번에 많이 보내지 말고 **우선순위 1·2번부터 두세 건씩** 보내면 된다.
